# Angular Playground

Angular experiments, starting with a PrimeNG landing page.

## Features

- Angular + PrimeNG
- Karma/Jasmine test setup

## Tech Stack

- Angular
- TypeScript
- PrimeNG

## Getting Started

```bash
git clone https://github.com/ghostland-dev/angular-playground.git
cd angular-playground
cd Angular/project-01-landing-page
npm install
npm start
```

Other scripts:

- `npm run build`: ng build
- `npm run test`: ng test

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fghostland-dev%2Fangular-playground&root-directory=Angular%2Fproject-01-landing-page)

Click the button to deploy your own copy on Vercel in one step.

The app lives in the `Angular/project-01-landing-page` folder, which the button sets as the Vercel root directory.
